# HARAV-SASSON — שיעורי הרב: תמלול, סיכום ושליפת מקורות

המנהל מעלה הקלטת שיעור → תמלול (Gemini) → סיכום + זיהוי המקורות שהרב ציטט → התאמה אוטומטית לטקסט המקורי
בספרים שבספרייה → דף שיעור ציבורי עם סיכום, המקורות (עם הקטע המלא מהספר) והתמלול.

## הרצה מקומית
```
pip install -r requirements.txt
copy .env.example .env      # למלא ADMIN_PASSWORD ו-GEMINI_API_KEY
python app.py               # http://127.0.0.1:5060
python tests/smoke.py       # בדיקת עשן (בלי AI)
```

## מילוי הספרייה
1. **Sefaria (אוטומטי):** `python sefaria_import.py --preset` (או שמות ספציפיים; `--list` להצגת הרשימה).
2. **העלאה ידנית:** `/admin/library` — txt / docx / pdf (חייב שכבת טקסט) / JSON של Sefaria.
   בשדה "כינויים" כדאי לרשום את הדרכים שהרב אומר את שם הספר — זה משפר את ההתאמה.

## הקלטות ארוכות
הקלטה מעל ~25 דקות מפוצלת אוטומטית (ffmpeg) למקטעי 20 דקות עם חפיפה של 15 שניות, מתומללת במקביל (3 במקביל),
ומחוברת מחדש (הכפילות באזור החפיפה מוסרת). מקטע שנכשל נשמר ב-cache ולא מתומלל שוב ב"נסה שוב".
הגדרות: `CHUNK_MINUTES`, `CHUNK_OVERLAP`, `TRANSCRIBE_WORKERS`. הסיכום והאיתור רצים על התמלול המלא.

## מילון קיצורים (ניהול ← מילון)
`glossary_seed.txt` הוא ערכי פתיחה (לבדיקה והשלמה!). אחרי עריכה באתר — "בנה אינדקס מחדש". המילון: (1) מוסיף לאינדקס את
פירוש הקיצור שבפסקה, כך ש"אריך אנפין" שהרב אמר ימצא את א"א שבספר; (2) מועבר ל-AI בניתוח ובאימות ההתאמה.

## ספרים סרוקים / PDF עם טקסט פגום
בהעלאה (ניהול ← ספרייה) לסמן "OCR ב-Gemini", או משורת הפקודה: `python ocr_pdf.py <pdf> --title ".." --start 1 --end 12`.

## איך השליפה עובדת
1. Gemini מחלץ מהתמלול כל ציטוט/הפניה (`quote`, `source_guess`, זמן).
2. חיפוש FTS5 (trigram, בלי ניקוד/אותיות סופיות/קידומות) בכל הספרייה, עם בונוס לספר שהוזכר.
3. Gemini בוחר את המועמד הנכון ומחזיר ביטחון. מעל 0.6 — מוצג לציבור; מתחת — רק למנהל ("לא בטוח").
4. המנהל יכול לאשר / לדחות / להסתיר / להחליף פסקה לפי מספר. אישורים ידניים נשמרים בעיבוד מחדש.

## פריסה (Render)
Procfile: `web: gunicorn app:app --workers 1 --threads 8 --timeout 600`. עובד אחד בלבד (העיבוד רץ ב-thread).
`DATA_DIR` צריך להצביע על דיסק קבוע; הספרייה ב-SQLite.

## הערות
- שיעור ארוך מאוד (מעל ~90 דק') — לפצל לקבצים, כי פלט התמלול מוגבל.
- זכויות יוצרים: להעלות רק טקסטים שמותר (Sefaria CC-BY-SA, נחלת הכלל, או באישור המוציא לאור). האתר מוגדר `noindex`.
